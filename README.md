# Propiska AI Assistant (Telegram)

Lightweight webhook bot designed for deployment from a phone via GitHub + Render.

## Features
- Client FAQ with optional Gemini API text generation
- Saves incoming messages as leads and forwards them to the configured admin chat
- Creates Telegram post drafts using `/draft topic`
- **Never publishes a post automatically**: an admin must tap "Опубликовать"
- `/stats` reports saved leads and pending drafts

## Important limitations
- This is an initial starter, not yet production-hardened.
- Render free instances may sleep and their local filesystem is ephemeral. SQLite at `/tmp` is not durable: use a managed database before relying on lead history.
- Telegram bots cannot read DMs sent to a separate personal manager account. This bot only sees messages sent to the bot itself.
- Do not ask clients to send passport scans or sensitive identity data through this bot.
- The AI output may be wrong. Review every draft and client-facing answer.

## Deploy from iPhone
1. Open this repository on GitHub.
2. Create a free Render account and choose **New > Blueprint**; connect this repository.
3. Render will ask for environment variables. Set:
   - `TELEGRAM_BOT_TOKEN`: token from @BotFather (keep secret)
   - `TELEGRAM_ADMIN_ID`: numeric Telegram user ID of the administrator
   - `TELEGRAM_CHANNEL_ID`: channel ID (often `@Moskva_propiska` if the bot can post there)
   - `GEMINI_API_KEY`: optional key from Google AI Studio
   - `WEBHOOK_SECRET`: generated by Render blueprint
4. After deployment, copy the public Render URL (for example `https://your-service.onrender.com`).
5. Set the webhook by opening this URL in a browser, replacing values locally:
   `https://api.telegram.org/bot<TOKEN>/setWebhook?url=<RENDER_URL>/telegram/webhook&secret_token=<WEBHOOK_SECRET>`
   Do not share that URL: it contains your bot token.
6. Add the bot as an administrator of the channel with permission to publish posts.

## Commands
- `/start` — client greeting
- `/draft <topic>` — administrator creates a draft
- `/stats` — basic counts

Before real use, add persistent database storage and test with a private test channel.
